Playground nixpkgs Parity Documentation GitHub

Derivations, computed in this tab. jinx reads Nix and writes TypeScript that evaluates to the same thing. The Nix on the left becomes the TypeScript in the middle, which runs here and prints its value on the right. A derivation call produces the .drv Nix would: same ATerm, same hash, same store path, no nix binary anywhere.

The two panes are joined by the source map: the cursor in one highlights the same expression in the other.
