What evaluating nixpkgs reads. Every top-level attribute of nixpkgs was evaluated to its derivation path with the files it read recorded (tools/attr-files.ts), which is what the nixpkgs page fetches ahead of an evaluation. Put together, the lists say which of nixpkgs' Nix files nothing reads, which ones everything reads, and how much of nixpkgs one package needs.

Files no attribute reads

A .nix file counts as read when some attribute loaded its module or read it as a file. What is left unread is mostly files for other platforms, tests.nix files a derivation path never forces, NixOS tests and modules, and the packages whose evaluation failed in the recording, which are not counted among the readers. The full list is unread.json.
