nixpkgs, evaluated in this tab. Every .nix file of nixpkgs was compiled to a TypeScript module. Type an attribute and the page runs those modules, fetched one by one as the evaluation reaches them, and computes pkgs.<attr>.drvPath and its output path: the same store paths Nix computes, with no evaluator on any server. If Hydra built the output, trynix can boot it in another tab.
